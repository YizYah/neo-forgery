# neo-forgery

A TypeScript library (`neo-forgery`) that provides an easy way to mock a `neo4j-driver` session for testing code that queries Neo4j. It is built with `tsc`, linted with ESLint, and tested with the AVA test runner.

## Setup

Install dependencies:

    npm install

## Verification

Type-check/lint with ESLint (`npm run lint`), build with the TypeScript compiler (`npm run build`), and run the AVA test suite (`npm test`).
